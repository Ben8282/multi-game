Docker Guide


To use Docker first make sure you have docker installed and git is optional but recommend

Git method (recommend)

first clone the repo with

git clone https://github.com/Ben8282/multi-game.git

Then cd into the folder with

cd multi-game

Non git method

First step Go to

https://github.com/Ben8282/multi-game/tree/main

then click the button labeled code and click download zip then take that zip file and extract it then open the extracted folder and you should see all the code and folders if you just see another folder open that and then you should see all the code and everything then open that folder in you terminal

now were on the step where both the git method and non git method should follow

first you need to build the image with

docker build -t multi-game .

then you need to run the image with

docker run -it multi-game

It is worth noting that Pong won't work properly inside Docker, even though all the other applications will.
