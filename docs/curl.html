Curl Guide


Run a curl command to install multi-game for you only works for unix based operating systems and this has not been fully implented yet we currently only have it working for

  • macOS
  • Debian GNU/Linux (and Ubuntu, Linux Mint and other distros that use apt)
  • Arch Linux (and Manjaro, EndeavourOS, Garuda and other distros that use pacman)
  • Gentoo Linux (and Calculate Linux and other distros that use emerge)

To be added

  • Fedora (and RHEL, Rocky Linux, AlmaLinux and other distros that use dnf)
  • openSUSE (Tumbleweed, Leap and SUSE Linux Enterprise, which use zypper)
  • Alpine Linux (and postmarketOS and other distros that use apk)
  • Void Linux
  • Solus
  • NixOS
  • Guix System
  • FreeBSD (and GhostBSD)
  • DragonFly BSD
  • OpenBSD
  • NetBSD

To run

simply run in your terminal

curl -fsSL https://raw.githubusercontent.com/Ben8282/multi-game/main/install.sh | sh

then simply run this in your terminal

multi-game
